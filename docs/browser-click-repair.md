# 浏览器点击修复计划与实现（2026-10-23）

## 问题证据

最新吸虫作业会话中 `.el-checkbox nth=1` 耗时约 17 秒。定位时遍历所有候选，再过滤不可点击元素并选择 nth，会造成重复测量和序号偏移。点击成功只表示投递鼠标事件，不能代表选项选中；失败后的自动二次点击可能将复选框取消。

## 修复步骤与验收

1. 在原始 DOM/AX 候选中先选 nth（1 起），只测量指定节点；缺失、隐藏、遮挡时报告该目标的错误，不换成后续节点。CSS 未指定 nth 时保持 querySelector 的第一个目标语义。
2. 投递事件前确认元素盒子连续两次稳定；超时返回失败。保留遮挡、可见性及 frame/session 检查。
3. 读取原生 input.checked，支持 label.control、包装元素中的 input、ARIA checkbox/radio。鼠标操作后轮询目标状态，连续两次符合预期才成功。
4. 新增 browser_set_checked，已符合状态则直接返回，不再切换。禁止直接取消 radio，不通过改 checked 属性绕过事件。
5. 支持最多 40 项的顺序批处理。整批参数/ref 预检后才执行；逐项确认，失败或用户停止时中断并返回部分结果。建议按题目范围/ref 定位，不按全页序号猜测。
6. 对已投递但结果不确定的点击禁止自动补点；保留实际错误，让 Agent 重新观察再决定。

## 验证

- Rust：候选顺序、目标隐藏、nth 越界。
- DOM：实际部署的状态探针，覆盖实时 checked、关联 label、radio、禁用、节点替换及 ARIA 控件。
- TypeScript：批量预检、失效 ref、顺序停止、frame 保留、false 状态与不重复点击。
- 构建与类型检查；原生改动需重启应用后再进行真实页面联调。不自动操作或提交当前用户作业。

## 范围与限制

整页完整记录和 Agent 工具调用方式保留；新选项协议目前由 macOS CEF 实现，其它引擎明确返回不支持。不自动提交表单、不替用户跳过验证。未推送。

## 12:39 截图绑定失败复盘

- 日志同时出现截图/脚本绑定失败和连续空快照。旧选择器会排除其它标签占用的 target，关闭标签却没有清理两份占用缓存，因此只有一个 page 仍可能被全部排除。单靠网址或唯一剩余页面也无法可靠区分同网址标签。
- 绑定改为经原生 BrowserHost 的 DevTools 通道执行 Target.getTargetInfo，获取准确的 page target ID。身份与网址无关，不再使用占用排除、同域匹配、唯一页面猜测。原生创建回调绑定明确的 tab ID，不再任选一个待创建标签。
- 缓存会话使用前验证仍属于原生 target；冷绑定和连接创建串行；旧连接的事件泵退出时不能清理新连接。关闭标签及 target 销毁清理相关状态。
- 刷新直接调用原生 Browser.reload，缺失标签返回错误；取消原来异步吞掉 CDP 失败却返回成功的实现。
- browser_get_page 保留读取错误并返回 ok=false，不再提示“快照暂时空”或让 Agent 继续盲等。
- 回归覆盖同网址多个标签、跨站跳转、唯一其它页面不能冒认、原生身份响应无效，以及初次读取/重连读取错误。应用内端到端截图仍需加载新原生构建后验证。

## 12:55–12:59 对话复盘：工具契约与提示

这轮截图已返回成功，主要失败集中在定位与对结果的判断：

1. AX 与 DOM 重复收录“提交/确定”，生成了实际不存在的第 2 个同名按钮；快照保存的 backend 又在 TS → Rust 定位参数中丢失。修复为保留节点身份，在 frame/loader 验证后定位原节点，不把精确 ref 重解释成 nth；合并时排除 AX/DOM 同名重复补充，真实同名节点按 backend 分别保留。
2. DOM 补充收进隐藏按钮、把 checkbox 当 textbox、把带 title 的静态标题当按钮。补充采集只保留可见的控件，使用唯一 DOM 路径，保留 checked/disabled；禁用控件不再作为“可点”建议。包住唯一复选框的选项容器改点 label，包住多选项的整题容器拒绝作为单个选项。
3. 截图内部重新采集快照，却没把新编号交给模型，导致旧 ref 失效。截图改为保留原快照。动作观测把 ref 重编号误认为 DOM 改变，也会让“点击了但没效果”被报告成变化；现在忽略编号差异、保留真实状态差异，并核对最终落地 URL。读取失败单独报告，过期缓存只作参考。
4. 关闭搜索后仍向模型提供 web_search，失败还建议凭已有知识继续。普通/浏览器对话的动态工具表现在按开关过滤；失败明确表示未取得联网证据。
5. 提取脚本的题干全部是“A.”却继续答题，勾选验证后宣称答案正确，实际得分 10/20。系统与工具提示区分题干完整性、答案依据、checked 状态、保存及提交回执；明确不确定性，不把工具成功当成答对依据。完成目标后报告真实结果，不因分数低擅自撤回重做或删参数重开作答页。
6. 补充 browser_press，使搜索框填写后可正常按 Enter，不再误点分页图标；沿用严格模式下的作答操作限制。移除活动标题里重复拼接的错误，空搜索结果如实显示未找到。
