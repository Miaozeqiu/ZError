# 智慧树使用记录

以下是 2026-10-29 在 macOS 内置 CEF 浏览器中观察到的现象，用于后续验证；不同课程和页面版本可能不同。记录不包含账号、课程编号、回答内容或登录状态。

## 已观察到的行为

- 课程问答支持从主页进入帖子，也可在“我的提问”“我的回答”检查已发布内容。主页的发布数量不等于有效数量或成绩；以该课程的规则和后续统计为准。
- 提交时可能出现安全验证。中断后先由用户完成验证，再确认上一条是否已经发布，避免重复提交。
- 标签页达到 16 个时，旧实现静默忽略新建和网页弹出的新页；关闭旧标签后能继续打开。现在应用会提示上限，Agent 点击结果在能关联到来源标签时返回 `tab_limit` 和 `clickDispatched`。
- 切换标签后，学习视频曾暂停。恢复时应重新观察播放状态，不能假定后台一直计时；视频小节完成标记也不等于整门课的所有作业均已完成。
- 某共享课作业页面在切到下一题时保存当前答案，最后一题有单独的保存入口；选项顺序可能变化。已交卷的旧 `dohomework` 页面仍可能显示作答控件，需看提交状态，不应仅根据网址判断能否作答。提交后从课程首页重新进入列表复核。
- 长任务曾在工具调用次数上限处中断；分批完成并核对已发布结果可以减少重复操作，但不保证平台最终判定有效。

## 仍待调查

- 一个多行标题的元素点击命中检查落到了外层节点；坐标点击随后成功。多行元素的盒子与落点是否是原因尚未确认，需要本地复现并比较可见片段及遮挡，不能据此认定所有缩放场景有问题。
- CUA 向论坛内嵌网页直接输入中文曾失败，而应用的 Agent 填写成功；具体原因尚未确定。
- 点击某次作业返回入口后应用曾退出，重新打开后可继续；仅有一次观察，尚不能判断原因。

新增问答页面识别和站点手册描述实际操作，不代表实现了智慧树作业解析器，也不代表真实发布自动计分。
