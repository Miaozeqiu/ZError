# macOS CEF 媒体能力与智慧树适配

智慧树页面解析、播放状态监控与视频解码是三个需要分别验证的环节。本文记录 2026-10-29 的本地验证条件，不表示所有智慧树产品页都已适配。

## 媒体能力

项目的 [CEF 说明](../src-tauri/cef/README.md) 提醒，默认 Spotify 预编译框架不含 H.264/AAC。历史对照中，同一内置浏览器可以播放本机提供的 VP8 WebM，而 H.264 MP4 返回媒体错误 4。这项本地对照可以排除课程服务器的影响，但不能据此解释所有站点播放错误。

在 macOS arm64 上换用带 `proprietary_codecs=true`、`ffmpeg_branding=Chrome` 的 CEF 后，本机 H.264/AAC MP4 和独立 AAC 均能正常结束，真实智慧慕课视频也能显示画面并推进时间。该结果属于当时实际安装包的验证；本 PR 不包含预编译框架、账号或浏览器登录态。

最终分发包仍需独立验证媒体能力。建议在应用内播放本机提供的 WebM、H.264/AAC MP4 和 AAC，检查时间推进、媒体错误及真实 `ended`；构建成功和 DOM 单元测试不能代替这项检查。

## 页面与监控

- `wisdom-mooc.zhihuishu.com/study/index` 在同一网址切换小节，读取媒体回执后才能决定是否复用监控。
- 只读目录卡按叶子条目计数，区分当前小节、目录完成图标和媒体结束。尚未加载的章节不能被当作完成。
- 随堂练习提交后可能自动关闭弹窗，但视频仍暂停，需要重新确认播放状态。
- 本地进度插值只用于显示，不能产生完成事件；完成状态仍需重新读取平台目录核对。

该 PR 在最新统一 Agent 工作区提供按需读取的 `study` 数据，不恢复旧版已经移除的浏览器侧栏，也没有实现完整的智慧树作业解析器。页面结构变化、其他智慧树产品布局及最终安装包的媒体回归仍需各自验证。
