# 在浙学

本站是 **在浙学**（zjooc.cn）。智慧树是 zhihuishu.com，步骤在 `sites/zhihuishu.com/`。

## 目录

- 页面：`/plan` 左侧树
- 点：带播放图标的叶子节名
- 框：无
- 结果：进入播放页
- 坑：父节点是章名，点了不会进播放页

## 播放页

- 页面：`/plan/detail` 顶栏页签
- 点：这一节里的视频页签名
- 框：播放器所在 iframe
- 结果：切到那一条视频
- 坑：左侧仍是整门课的目录树，切视频点顶栏页签，不要回目录页

## 播放

- 点：播放按钮上的字；没有字就点原生 video
- 结果：`playing` 为真后再 `browser_watch`
- 坑：不要只点当前看得见的那条就算完成这一节
