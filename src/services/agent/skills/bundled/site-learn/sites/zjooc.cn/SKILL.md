# 在浙学

本站是 **在浙学**（zjooc.cn）。智慧树是 zhihuishu.com，步骤在 `sites/zhihuishu.com/`。

## 目录

- 页面：`/plan` 左侧树
- 点：带播放图标的叶子节名
- 框：无
- 结果：进入播放页
- 坑：父节点是章名，点了不会进播放页

## 播放页

- 页面：`/plan/detail` 顶栏页签
- 点：这一节里的视频页签名
- 框：播放器所在 iframe
- 结果：切到那一条视频
- 坑：左侧仍是整门课的目录树，切视频点顶栏页签，不要回目录页

## 播放

- 点：播放按钮上的字；没有字就点原生 video
- 结果：`playing` 为真后再 `browser_watch`
- 坑：不要只点当前看得见的那条就算完成这一节

## 作业：题干与选项对应

- 页面：`/ucenter/student/course/study/.../homework/do/...`。
- 按每道题的独立 DOM 容器读取题型、题号、完整题干和本题选项。单选/多选分组可能各自从 1 编号，使用「题型 + 题号」区分。
- 本次验证中 input 的 name 为空，不能依赖 name 归题。选项需关联所在题目及其 label、value、checked 状态，再用最新快照的 ref 或题目内 selector 操作。
- 坑：从每个 input 向上寻找「包含标点、长度足够」的祖先，会误选包住多道题的外层容器，后面选项混入第一题。不能把重复的整页文字当作每题题干。
- 核对：每个选项只归属一道题；题目数、题型及选项数与页面一致；不按字数截断题干或用固定字数阈值认题。结构不符合时重新观察，不照搬临时提取脚本。
- 勾选验证只证明控件状态；保存、提交、评分仍需页面回执，不能据此声称答案正确。
