# 在浙学

本站是 **在浙学**（zjooc.cn）。智慧树是 zhihuishu.com，步骤在 `sites/zhihuishu.com/`。

## 登录

需要登录时调用 `browser_login_zjooc()`。工具使用网站设置中的凭据。出现图形验证码时请用户在当前页面输入并点击登录，完成后再次调用工具核对登录态。

## 目录

- 页面：`/plan` 左侧树
- 点：带播放图标的叶子节名
- 框：无
- 结果：进入播放页
- 坑：父节点是章名，点了不会进播放页

## 播放页

- 页面：`/plan/detail` 顶栏页签
- 点：这一节里的视频页签名
- 框：播放器所在 iframe
- 结果：切到那一条视频
- 坑：左侧仍是整门课的目录树，切视频点顶栏页签，不要回目录页

## 播放

- 进入指定小节播放页后调用 `browser_play_zjooc()`；用户指定某条视频时传页签全名 `title`。工具会确认视频时间推进并登记监控。
- 用户要求连续播放本小节时调用 `browser_play_zjooc({mode:"section"})`，宿主按页签顺序等待各视频自然结束。多小节任务按要求进入下一节，再次调用。
- 坑：不要只点当前看得见的那条就算完成这一节

## 自动作答

进入用户指定的作答页后调用 `browser_answer_zjooc()`。需要题库账号时，宿主会弹出 ZError 登录窗口，登录成功后继续当前批次。网站账号仍用于进入课程。

每批最多处理五题。收到 `nextOffset` 时，带上同一回执的 `assignment_id` 和新的 `offset` 继续。单题模式按用户指定范围通过网页的「下一题」切题。已有作答会保留，遇到 `needs_review` 或 `unverified` 要核对页面。

讲评页显示的正确答案会自动收集，完整试卷按需上传。作答时优先使用已公布答案，逐题回退到服务器题库、本地题库和模型。回执中的 `source` 可以区分答案来源，`filled` 表示网页已回读到所填内容。

## 作业：题干与选项对应

- 页面：`/ucenter/student/course/study/.../homework/do/...`。
- 按每道题的独立 DOM 容器读取题型、题号、完整题干和本题选项。单选/多选分组可能各自从 1 编号，使用「题型 + 题号」区分。
- 本次验证中 input 的 name 为空，不能依赖 name 归题。选项需关联所在题目及其 label、value、checked 状态，再用最新快照的 ref 或题目内 selector 操作。
- 坑：从每个 input 向上寻找「包含标点、长度足够」的祖先，会误选包住多道题的外层容器，后面选项混入第一题。不能把重复的整页文字当作每题题干。
- 核对：每个选项只归属一道题；题目数、题型及选项数与页面一致；不按字数截断题干或用固定字数阈值认题。结构不符合时重新观察，不照搬临时提取脚本。
- 勾选验证只证明控件状态；保存、提交、评分仍需页面回执，不能据此声称答案正确。
