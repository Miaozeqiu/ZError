# 智慧树课程问答

适用 `qah5.zhihuishu.com/qa.html`。先核对课程名和用户要求。登录与验证码规则见 `read_agent_skill_file(site-learn, sites/zhihuishu.com/SKILL.md)`。

## course-qa：课程问答

首页路由为 `#/web/home/<课程号>`。页面版本可能变化，先读当前快照并核对页头课程名称。标题或“最新”标签不一定是 button，定位失败先重新观察，不要连续盲点。

### 提问与发布

1. 右下提问入口在已验证布局中是 `div.ask-btn[title="提问"]`。隐藏弹窗中的“提问”可能被快照识别成 button，按文字还可能误点“我的提问”。只读确认真实可见结构后，可以用 `browser_click({ selector: ".ask-btn" })` 点击。
2. 弹窗出现后，用当前快照中 textbox“写下你的问题，以问号结尾”的 ref 填正文，提交前核对输入框。若“立即发布”不在快照中，只读确认可见弹窗后，可点击 `.questionDialog .up-btn`。
3. 每次提交后，核对弹窗已关闭、最新列表出现本人原文，再检查“我的提问”数量或列表。隐藏 textarea 可能仍留在快照中，不能据一次点击或一个残留输入框判断成功或失败。

### 回答与本人列表核对

- 先打开正确的其他同学原帖，按用户授权填写相关回答。发布后确认该帖中的本人内容，或在“我的回答”复查，再处理下一条。
- 首页“我参与的”卡片在已验证布局中使用包含 `.qa_jion_num` 和 `.qa_jion_name` 的 li，依次是我的回答、我的评论、我的提问、我的围观。若文字点击落到内部 div，只读确认当前布局后，可用 `browser_click({ selector: "li:has(.qa_jion_name)", nth: 3 })` 打开我的提问；不要在未核对布局时依赖这个序号。
- 我的提问路由为 `#/web/myJoin/<课程号>?recruitId=...&role=2&type=topic`。条目可按 `.question-content` 核对，完整原文也可能位于 title 属性。不要重复统计父 div 与子 span；去重核对内容并检查“没有更多了”，再判断是否已加载全部。

### 中断与成绩

- 验证码、登录失效或频率限制出现时停止，由用户处理。中断恢复后先检查上一条是否已发布，避免重复提交。
- 主页数量是发布统计，不等于有效数量或已计分。有效性、刷新时间和分数规则以该课程页面为准，不能把某次任务的目标数量写成固定规则。
- 新详情打不开时检查标签页上限；关闭不用的标签后再打开链接。涉及提交的操作应先核对页面结果，不能因网址没变就重新提交。
- 每完成一个帖子的操作并核对结果后，用 `browser_tabs({ action: "list" })` 查看本对话标签。若该临时详情页不再需要且没有未保存内容，用 `browser_tabs({ action: "close", id: "列表中的标签 id" })` 关闭，回到来源页继续；不要关闭正在播放、仍需核对或最后一个入口页。关闭后重新读取页面再操作。
