# 把站点写成经验

新站先看快照摸路。走通一个可复用阶段后，先核对 `sites/<主机>/SKILL.md`，有新经验才更新。宿主记录的【做过】不是 Skill 已保存的证据。

一个网站可以使用多个域名。已确认关联的登录服务归到主网站，步骤写入同一份 `site-learn/sites/<主网站域名>/SKILL.md`；不另建登录网站，也不把其他网站的经验写到学习通。具体保存位置以工具返回路径为准。

## 一条经验写什么

```markdown
## 目录
- 页面：课程计划
- 点：左侧树里的节名（叶子，带播放图标）
- 框：无
- 结果：进入播放页
- 坑：父节点是章名，点了不会进播放页
```

固定四件事：哪一页、点哪个字、在哪个框、坑在哪。框名用快照里的 iframe 标题或 mid。

## 顺序

1. `get_page` 看当前页快照。快照按 iframe 分段，跨域框会标 `cross-origin`。
2. 用 ref 点中目标，确认网址或页面变了。
3. 先用 `read_agent_skill_file` 读取本站文件。已有覆盖则跳过；需要更新时保留已有正文，合并增量，通过 `write_agent_skill_file` 写回完整文件。不存在时才新建。
4. 阶段结束时检查一次，不必每个点击都写。任务收尾在 `browser_finish` 的 `learning` 中报告 updated / covered / no_new / deferred 和具体依据。

记录已观察到的页面结构、可靠定位范围、验证结果和失败边界。读取题目时说明怎样把题干与选项限制在同一题目容器内，核对题型、题号及选项数量；不保存这次作业答案、临时 ref、账号、密码或验证码。未经验证的分数推测、字数截断阈值和一次性补救脚本不能当通用步骤。结构不符时重新观察，不能盲用旧经验。

验证直接在当前真实网页中进行，确认点击、跳转或页面回执。网站资料只保留已验证的操作经验和导航配置，不生成测试网页或保存整页 HTML 快照。

权限拒绝或写入失败时保留网页任务的真实结果，报告经验未保存；不要重复申请授权，也不要重新答题或提交。

播放键没有字、是原生 `<video>` 时，点那个视频框里的 video ref，然后 `browser_watch`。
