# 把站点写成经验

新站先看快照摸路。走通一段，立刻写进 `sites/<主机>/SKILL.md`。宿主也会把成功且页面有变化的点击记成【做过】，下次按当前图谱节点提示。

## 一条经验写什么

```markdown
## 目录
- 页面：课程计划
- 点：左侧树里的节名（叶子，带播放图标）
- 框：无
- 结果：进入播放页
- 坑：父节点是章名，点了不会进播放页
```

固定四件事：哪一页、点哪个字、在哪个框、坑在哪。框名用快照里的 iframe 标题或 mid。

## 顺序

1. `get_page` 看当前页快照。快照按 iframe 分段，跨域框会标 `cross-origin`。
2. 用 ref 点中目标，确认网址或页面变了。
3. `write_agent_skill_file` 把这一步追加到 `sites/<主机>/SKILL.md`。
4. 下一页重复。不要等整门课走完再写。

播放键没有字、是原生 `<video>` 时，点那个视频框里的 video ref，然后 `browser_watch`。
