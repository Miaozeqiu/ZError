# 学习通作业 / 章节测验

看快照点选项。作答页可以用 `browser_get_page` 只读看题。不要写 locators.json / see.json。

## 流程

- 课程作业：在课程壳点侧栏「作业」。已经在「任务」就改点「作业」。名单在页内 iframe，不要 `navigate` 打开 `mooc2/work/list`。
- 从名单点作业名才进作答页。章节播放里的测验仍在 studentstudy 内，快照会多一层 iframe。
- 快照里出现「未交」作业名就点那一行。
- 先按下文绑定题号、题干、选项与元素，再一题一题作答。单选点实际选项的字母或文字，多选逐个点；判断按页面实际显示的「对/错」「正确/错误」选择，不假定 A/B 对应关系。填空写入对应输入框。
- 按用户授权保存或提交。用户要求完成章节任务且未排除答题时，完成章节测验并核对提交回执；只要求暂存时不提交。
- 已完成/待批阅不要再交。
- 当前是文本模型且题干或选项必须看图才能判断时，说明无法读取并报告未完成，不猜答案，不把跳过算作完成。

## 题号与元素必须一起绑定

- 以页面实际显示的题号为准。只读提取返回按 DOM 顺序排列的数组，每项同时保留：页面显示题号、完整题干、当前 frameId/loaderId、该题容器 ID 或 ref，以及本题选项的显示标签、原文与定位信息。换行是题干或选项的一部分，不用换行拆题。
- 元素 ID、数据库 qid 大小和题型分组都不能代表显示题序。不要返回以数字 ID 为键的对象再按键顺序配题：JavaScript 会将整数键重排，第三题的 ID 完全可能比第四题大。没有显示题号时保留 DOM 顺序和完整原文，不自行从 ID 生成题号。
- 点击前，在同一个题目容器内核对「显示题号 + 题干原文 + 元素 ID/ref」，再用该容器内的真实选项定位。不能只核对选项文字，也不能把另一题的 ID 套到当前题号。
- 点击后按「页面题号 → 题干 → 已选答案」逐题核对，不能仅确认每个 qid 都有选项被选中。提交前重新读取有序列表，核对全部题号与答案对应关系；有疑义时用当前页面截图复核。截图无法辨认时报告阻塞。

## 坑

- 题目常在 `doHomeWork` 或 `ananas/modules/work` 里面再套一层，按快照的框点，不要点顶层同名按钮。
- 快照读不到题时先确认已经在作答页，再用新快照中的精确 frameId/loaderId 只读检查题目容器；不要复用其他页面的 frame 或从 ID 猜题序。
