# 学习通作业 / 章节测验

看快照点选项。作答页可以用 `get_page` 只读看题。不要写 locators.json / see.json。

## 流程

- 课程作业：在课程壳点侧栏「作业」。已经在「任务」就改点「作业」。名单在页内 iframe，不要 `navigate` 打开 `mooc2/work/list`。
- 从名单点作业名才进作答页。章节播放里的测验仍在 studentstudy 内，快照会多一层 iframe。
- 快照里出现「未交」作业名就点那一行。
- 一题一题点选项。单选/判断点字母，多选逐个点，填空写入对应输入框。
- 用户没说交卷就点「暂时保存」。要交再点「提交」，确认框点「确定」。
- 已完成/待批阅不要再交。
- 当前是文本模型时跳过只有图的题。

## 坑

- 题目常在 `doHomeWork` 或 `ananas/modules/work` 里面再套一层，按快照的框点，不要点顶层同名按钮。
- `inspect` 读不到题时先确认已经在作答页，再用快照看框。
